# Погода в Pure Data через Lua

## Требования:
- PlugData: https://plugdata.app/

## Файлы:
- weather.pd — основной патч
- weather_fetcher.lua — скрипт для получения данных

## Инструкция:
1. Замените "ВАШ_API_КЛЮЧ" в weather_fetcher.lua.
2. Откройте weather.pd в PlugData.
3. Нажмите кнопку, чтобы получить данные.
